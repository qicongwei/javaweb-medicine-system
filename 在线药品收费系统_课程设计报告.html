一、需求分析

1.1 项目背景

随着互联网技术的快速发展和医疗信息化进程的推进，传统的线下药品购买模式已难以满足人们日益增长的便捷就医需求。在线药品收费系统旨在为用户提供一个安全、便捷、高效的药品浏览与在线交易平台，实现药品信息的数字化管理、在线选购、购物车管理、订单处理等核心功能。

本系统采用 Java Web 技术栈开发，基于 MVC 设计模式，综合运用 Servlet、JSP、JDBC、MySQL、Filter 等技术，是一个完整的前后端分离架构的 Web 应用系统。通过本课程设计，旨在深入理解并实践 Java Web 开发的全流程，掌握 MVC 架构的设计思想，提升软件工程实践能力。

系统面向两类用户角色：普通用户和管理员，分别提供不同的功能服务。

三、数据库设计

3.1 E-R关系模型

系统数据库 medicine_db 包含6张数据表，各表之间的关系如下：

users（用户表）
  │ 1:N
  ├── cart_items（购物车表） ──── N:1 ── medicines（药品表）
  │                                    │ N:1
  │                                   categories（分类表）
  │ 1:N
  └── orders（订单表）
        │ 1:N
        └── order_items（订单明细表） ── N:1 ── medicines

核心关系说明：一个用户可以拥有多个购物车项和多个订单；一个订单包含多个订单明细；一种药品属于一个分类；订单明细中保存药品名称快照，确保历史订单数据不受药品信息修改影响。

4.2.1 DBUtil — 数据库连接工具类

DBUtil 封装了数据库连接的获取和资源关闭逻辑，采用静态代码块加载JDBC驱动：

DBUtil.java — 数据库连接工具
package com.medicine.util;

import java.sql.*;

public class DBUtil {
    private static final String DRIVER = "com.mysql.jdbc.Driver";
    private static final String URL = "jdbc:mysql://localhost:3306/medicine_db"
        + "?useUnicode=true&characterEncoding=utf-8"
        + "&useSSL=false&serverTimezone=Asia/Shanghai"
        + "&allowPublicKeyRetrieval=true";
    private static final String USER = "root";
    private static final String PASSWORD = cfg("medicine.db.password", "MEDICINE_DB_PASSWORD", "");

    static {
        try {
            Class.forName(DRIVER);
        } catch (ClassNotFoundException e) {
            System.err.println("MySQL JDBC驱动加载失败: " + e.getMessage());
        }
    }

    public static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, USER, PASSWORD);
    }

    public static void close(Connection conn, Statement stmt, ResultSet rs) {
        try { if (rs != null) rs.close(); } catch (SQLException e) {}
        try { if (stmt != null) stmt.close(); } catch (SQLException e) {}
        try { if (conn != null) conn.close(); } catch (SQLException e) {}
    }
}

4.2.2 MedicineDAO — 分页查询与库存操作

MedicineDAO 实现了分页查询、分类筛选和关键词搜索功能，库存更新采用原子操作确保并发安全：

MedicineDAO.java — 分页查询与库存更新
// 分页查询所有药品（关联分类名）
public List<Medicine> findAll(int page, int pageSize) {
    List<Medicine> list = new ArrayList<>();
    String sql = "SELECT m.*, c.name AS category_name FROM medicines m "
               + "LEFT JOIN categories c ON m.category_id = c.id "
               + "ORDER BY m.id DESC LIMIT ?, ?";
    try (Connection conn = DBUtil.getConnection();
         PreparedStatement pstmt = conn.prepareStatement(sql)) {
        pstmt.setInt(1, (page - 1) * pageSize);
        pstmt.setInt(2, pageSize);
        ResultSet rs = pstmt.executeQuery();
        while (rs.next()) {
            list.add(extractMedicine(rs));
        }
    } catch (SQLException e) {
        e.printStackTrace();
    }
    return list;
}

// 库存原子更新（下单减库存，WHERE条件确保不超卖）
public boolean updateStock(int id, int quantity) {
    String sql = "UPDATE medicines SET stock = stock - ? WHERE id = ? AND stock >= ?";
    try (Connection conn = DBUtil.getConnection();
         PreparedStatement pstmt = conn.prepareStatement(sql)) {
        pstmt.setInt(1, quantity);
        pstmt.setInt(2, id);
        pstmt.setInt(3, quantity);
        return pstmt.executeUpdate() > 0;
    } catch (SQLException e) {
        e.printStackTrace();
        return false;
    }
}

4.2.3 OrderDAO — 事务处理

OrderDAO 的 createOrder 方法是系统最核心的数据操作，采用JDBC事务确保数据一致性。事务包含4个步骤：插入订单 → 插入订单明细 → 减库存 → 清空购物车，任一步骤失败则全部回滚。

OrderDAO.java — 事务创建订单
public boolean createOrder(Order order) {
    Connection conn = null;
    try {
        conn = DBUtil.getConnection();
        conn.setAutoCommit(false);  // 开启事务

        // 1. 插入订单主表
        String orderSql = "INSERT INTO orders(order_no, user_id, total_amount, "
            + "status, receiver_name, receiver_phone, receiver_address) "
            + "VALUES(?, ?, ?, 'pending', ?, ?, ?)";
        PreparedStatement orderPstmt = conn.prepareStatement(
            orderSql, Statement.RETURN_GENERATED_KEYS);
        // ... 设置参数并执行
        ResultSet rs = orderPstmt.getGeneratedKeys();
        int orderId = rs.getInt(1);

        // 2. 插入订单明细 + 减库存（循环处理每个商品）
        for (OrderItem item : order.getItems()) {
            // 插入明细
            itemPstmt.addBatch();
            // 减库存（检查库存是否充足）
            int affected = stockPstmt.executeUpdate();
            if (affected == 0) {
                conn.rollback();
                return false;  // 库存不足，回滚
            }
        }
        itemPstmt.executeBatch();

        // 3. 清空用户购物车
        clearPstmt.executeUpdate();

        conn.commit();  // 提交事务
        return true;
    } catch (SQLException e) {
        try { if (conn != null) conn.rollback(); } catch (SQLException ex) {}
        return false;
    } finally {
        try { if (conn != null) { conn.setAutoCommit(true); conn.close(); } }
        catch (SQLException e) {}
    }
}

4.3.1 LoginServlet — 登录控制器

LoginServlet.java — 用户登录
@WebServlet("/LoginServlet")
public class LoginServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws ServletException, IOException {
        String username = req.getParameter("username");
        String password = req.getParameter("password");

        UserDAO userDAO = new UserDAO();
        User user = userDAO.login(username, password);  // DAO中自动MD5加密比对

        if (user != null) {
            HttpSession session = req.getSession();
            session.setAttribute("user", user);
            // 根据角色跳转不同页面
            if ("admin".equals(user.getRole())) {
                resp.sendRedirect(req.getContextPath() + "/admin/index.jsp");
            } else {
                resp.sendRedirect(req.getContextPath() + "/index.jsp");
            }
        } else {
            req.setAttribute("error", "用户名或密码错误！");
            req.getRequestDispatcher("/login.jsp").forward(req, resp);
        }
    }
}

4.4.2 AuthFilter — 登录验证过滤器

AuthFilter 维护一个公开路径白名单，药品浏览、登录注册等页面不需要登录即可访问，购物车、订单、后台管理则需要先登录。

AuthFilter.java
@WebFilter("/*")
public class AuthFilter implements Filter {
    private static final String[] PUBLIC_PATHS = {
        "/", "/index.jsp", "/login.jsp", "/register.jsp",
        "/css/", "/error/", "/medicine/",
        "/LoginServlet", "/RegisterServlet",
        "/MedicineListServlet", "/MedicineDetailServlet"
    };

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
            FilterChain chain) throws IOException, ServletException {
        HttpServletRequest req = (HttpServletRequest) request;
        String path = req.getRequestURI().substring(req.getContextPath().length());

        if (isPublicPath(path)) {
            chain.doFilter(request, response);
            return;
        }

        HttpSession session = req.getSession(false);
        if (session == null || session.getAttribute("user") == null) {
            req.getSession().setAttribute("error", "请先登录后再进行操作");
            resp.sendRedirect(req.getContextPath() + "/login.jsp");
            return;
        }

        chain.doFilter(request, response);
    }
}

4.4.3 AdminFilter — 管理员权限过滤器

AdminFilter.java
@WebFilter("/admin/*")
public class AdminFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
            FilterChain chain) throws IOException, ServletException {
        HttpServletRequest req = (HttpServletRequest) request;
        HttpServletResponse resp = (HttpServletResponse) response;
        HttpSession session = req.getSession(false);

        if (session == null || session.getAttribute("user") == null) {
            resp.sendRedirect(req.getContextPath() + "/login.jsp");
            return;
        }

        User user = (User) session.getAttribute("user");
        if (!"admin".equals(user.getRole())) {
            resp.setContentType("text/html;charset=UTF-8");
            resp.getWriter().write("<script>alert('没有管理员权限！');history.back();</script>");
            return;
        }

        chain.doFilter(request, response);
    }
}

五、关键技术实现

5.1 事务处理

订单创建是系统最关键的业务操作，涉及订单表、订单明细表、药品库存表、购物车表四张表的联动修改。通过JDBC事务（setAutoCommit(false) + commit/rollback）确保数据一致性：

conn.setAutoCommit(false);              // 开启事务
  ① INSERT INTO orders ...             // 插入订单
  ② INSERT INTO order_items ... (循环)  // 插入明细
  ③ UPDATE medicines SET stock=stock-?  // 减库存（检查超卖）
  ④ DELETE FROM cart_items ...          // 清空购物车
conn.commit();                          // 全部成功 → 提交
  -- 或 conn.rollback();                -- 任一步骤失败 → 回滚
防超卖设计：减库存SQL使用 WHERE id=? AND stock>=? 条件，确保库存不足时UPDATE影响行数为0，此时触发回滚，防止超卖。

5.2 密码加密

用户密码采用MD5算法加密后存储，登录验证时对输入密码同样进行MD5加密后比对。MD5Util工具类封装了加密和验证逻辑：

MD5Util.java — 密码加密工具
public class MD5Util {
    public static String md5(String input) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] bytes = md.digest(input.getBytes());
            StringBuilder sb = new StringBuilder();
            for (byte b : bytes) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();  // 32位小写十六进制
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException("MD5加密失败", e);
        }
    }

    public static boolean verify(String input, String encrypted) {
        return md5(input).equals(encrypted);
    }
}

5.3 分页与搜索

药品列表支持分页浏览和关键词搜索。分页采用MySQL的LIMIT子句，搜索支持药品名称、生产厂家、描述三个字段的模糊匹配：

分页搜索SQL
-- 分页查询（关联分类名）
SELECT m.*, c.name AS category_name
FROM medicines m
LEFT JOIN categories c ON m.category_id = c.id
ORDER BY m.id DESC
LIMIT ?, ?   -- offset=(page-1)*pageSize, count=pageSize

-- 关键词搜索（多字段模糊匹配）
SELECT m.*, c.name AS category_name
FROM medicines m
LEFT JOIN categories c ON m.category_id = c.id
WHERE m.name LIKE ? OR m.manufacturer LIKE ? OR m.description LIKE ?
ORDER BY m.id DESC
LIMIT ?, ?

5.4 权限控制

系统采用基于角色的访问控制（RBAC），通过Filter链实现多层权限校验：

请求进入
  → EncodingFilter（编码处理，所有请求）
  → CartFilter（购物车数量注入，所有请求）
  → AuthFilter（登录验证，仅/cart/*, /order/*, /admin/*）
  → AdminFilter（管理员验证，仅/admin/*）
  → Servlet（业务处理）

权限分为两级：

  • 普通用户（user）：可浏览药品、管理购物车、管理自己的订单
  • 管理员（admin）：拥有普通用户所有权限，额外可访问后台管理所有功能

7.2 开发过程中的问题与解决

在开发过程中遇到了多个技术问题，通过查阅资料和调试逐一解决：

7.2.1 中文乱码问题

问题：JSP页面和数据库交互时出现中文乱码。解决：通过EncodingFilter统一设置UTF-8编码，JSP页面添加pageEncoding="UTF-8"声明，数据库连接URL添加characterEncoding=utf-8参数，MySQL数据库和表使用utf8字符集。

7.2.2 MySQL 8.0认证问题

问题：MySQL 8.0默认使用caching_sha2_password认证插件，JDBC 5.1驱动连接失败。解决：在JDBC连接URL中添加allowPublicKeyRetrieval=true参数。

7.2.3 Filter注解不生效

问题：web.xml中设置了metadata-complete="true"，导致@WebServlet和@WebFilter注解不被扫描。解决：在web.xml中显式注册所有Servlet和Filter的映射关系。

7.2.4 订单取消库存恢复

问题：取消已付款订单时库存未恢复。解决：在OrderDAO.updateStatus()方法中，当状态为"cancelled"时，先查询订单明细，循环恢复每种药品的库存。

7.2.5 空指针异常防护

问题：OrderDAO的finally块中conn.close()未做null检查。解决：将conn.close()移入if(conn!=null)代码块内，确保异常情况下不会产生NPE。

7.3 学习体会

通过本次课程设计，我对Java Web开发有了更加深入的理解和实践。主要收获如下：

  1. MVC设计模式的深入理解：通过实际项目开发，深刻体会到MVC分层架构带来的好处——代码结构清晰、职责分离、易于维护。Model层专注于数据结构，DAO层封装数据库操作，Controller层处理业务逻辑，View层负责展示，各层之间通过接口通信，降低了耦合度。
  2. JDBC事务的重要性：在实现订单创建功能时，深刻认识到事务处理的重要性。如果不用事务，当减库存成功但清空购物车失败时，就会出现数据不一致。通过setAutoCommit(false)和commit/rollback机制，确保了多表操作的原子性。
  3. Filter的灵活运用：Filter不仅用于编码过滤，还能实现权限控制、日志记录、数据预处理等功能。本系统通过4个Filter实现了编码统一、登录验证、权限控制、购物车数量注入，大大简化了Servlet中的重复代码。
  4. 前端工程化思维：虽然使用的是JSP而非现代前端框架，但通过CSS变量体系、公共组件复用、响应式布局等实践，体会到了前端工程化的重要性。好的UI设计不仅关乎美观，更影响用户体验。
  5. 调试与问题解决能力：在开发过程中遇到了各种问题（乱码、端口冲突、类版本不兼容等），通过查阅文档、分析日志、逐步调试，培养了解决复杂技术问题的能力。
